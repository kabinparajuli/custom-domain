# Fishing Master Pro v2 — Virtual Arcade

Open `index.html` in Chrome/Safari/Edge.

### Improvements
- Pointer/touch-first controls with pointer events.
- Direct tap targets on fish.
- Dynamic fish movement and respawning.
- 60-second finite rounds.
- Daily reward can be claimed only once per calendar day.
- Missions pay only once after completion.
- No unlimited free-coin button.
- Combo decay, XP/levels, finite tournament timer, shop ownership and local persistence.
- Responsive mobile/desktop interface.

This is a virtual-points arcade game. Points have no cash value and there are no deposits, withdrawals or real-money wagering features.
